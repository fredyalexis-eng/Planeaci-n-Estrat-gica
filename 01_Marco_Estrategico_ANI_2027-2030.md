## 1. RESUMEN EJECUTIVO

| Decisión | Contenido |
|---|---|
| **Arquitectura** | 2 Focos = Iniciativas del PND. **Todo proyecto ANI 2027-2030 debe trazarse a 1 Foco.** |
| **Instrumento** | Tabla PEI: `FOCO → OBJETIVO ESTRATÉGICO → PROYECTO → UNIDAD DE MEDIDA → META 2030 → DETALLE` |
| **Foco 1** | Infraestructura dinamizadora para la conectividad y el desarrollo (oferta multimodal) |
| **Foco 2** | Ruta social y gestión preventiva de conflictos (viabilidad territorial) |
| **Riesgo mayor** | Proyectos huérfanos, metas no medibles, desbordamiento de competencia en Foco 1 |
| **Próximo paso** | Llenar la tabla con reglas de validación + scoring 1-5 (ver §5) |

**Mensaje ejecutivo:** Los 2 focos no compiten, se necesitan. Foco 1 sin Foco 2 = obra bloqueada. Foco 2 sin Foco 1 = gestión sin resultado físico.

## 3. VISUALIZACIONES

### 3.1 Mapa estratégico (causa → efecto)

```
CAPACIDADES (F2)
  Social · Jurídica · Ambiental · Predial · Tecnológica
        ↓ habilita
PROCESOS INTERNOS
  Alertas tempranas · Diálogo permanente · Gestión predial/ambiental
        ↓ habilita
INFRAESTRUCTURA Y MOVILIDAD (F1)
  Corredores completos · Cuellos de botella eliminados · Modos articulados
        ↓ produce
DESARROLLO NACIONAL / TERRITORIAL
  Conectividad · Accesibilidad · Productividad regional
        ↓ impacta
CIUDADANO Y USUARIOS
  Seguridad vial · Accesibilidad · Confianza · Beneficios compartidos
        ↓ protege
GOBERNANZA + SOSTENIBILIDAD + FINANZAS
  Menos demandas · Recursos públicos protegidos · Resiliencia climática
```

**Lectura:** Sin capacidades (F2) no hay procesos; sin procesos no hay F1 viable; sin F1 no hay desarrollo; sin desarrollo no hay confianza ciudadana.

### 3.2 Árbol de problemas (síntesis desde las imágenes)

```
PROBLEMA CENTRAL
  Proyectos de infraestructura con baja viabilidad territorial
  y conectividad incompleta
        ├── CAUSAS DIRECTAS
        │     ├── Cuellos de botella y corredores incompletos (F1)
        │     ├── Conflictos no gestionados preventivamente (F2)
        │     └── Activos existentes no modernizados (F1)
        ├── CAUSAS INDIRECTAS
        │     ├── Capacidades sociales/jurídicas/ambientales/prediales débiles
        │     ├── Falta de conocimiento territorial y alertas tempranas
        │     └── Modos no articulados (carretero-férreo-fluvial-portuario-aeroportuario)
        └── CONSECUENCIAS
              ├── Demoras, sobrecostos, demandas contra el Estado
              ├── Desconfianza comunitaria, bloqueo de obras
              └── Pérdida de recursos públicos y reputación
```

### 3.3 Árbol de objetivos

```
OBJETIVO CENTRAL
  Infraestructura conectada, resiliente y socialmente viable
        ├── F1: Portafolio integrado multimodal
        │     ├── Completar corredores estratégicos
        │     ├── Eliminar cuellos de botella / mejorar accesos
        │     └── Modernizar activos con criterios transversales
        └── F2: Ruta social preventiva
              ├── Diálogo, confianza, participación, beneficios compartidos
              ├── Alertas tempranas + resolución oportuna
              └── Capacidades fortalecidas (5 frentes)
        └── IMPACTO: Conectividad para el desarrollo + menos conflictos
```

### 3.4 Teoría del Cambio (resumen)

| Eslabón | F1 | F2 |
|---|---|---|
| **Problema** | Desconexión, cuellos de botella, modos desarticulados | Conflictos, desconfianza, demandas |
| **Supuesto** | Si se completa el portafolio con criterios transversales, mejora la conectividad | Si hay diálogo preventivo y capacidades, baja el conflicto |
| **Intervención** | Portafolio integrado + modernización | Ruta social + alertas tempranas |
| **Producto** | Corredores, accesos, activos modernizados | Mesas, protocolos, sistema de alertas |
| **Resultado** | Movilidad, accesibilidad, resiliencia | Menos controversias, menos demandas |
| **Impacto** | Desarrollo territorial | Protección de recursos públicos |
| **Riesgo** | Desbordamiento de competencia, costo, clima | Capacidades no financiadas, tiempos de diálogo |
| **Indicador** | Ver §3.6 (a definir con línea base ANI) | Ver §3.6 (a definir con línea base ANI) |

### 3.5 Matriz Impacto vs. Esfuerzo (para el taller)

```
IMPACTO INSTITUCIONAL/NACIONAL ↑
  Alto │  [Quick Wins]        │  [Iniciativas Estratégicas]
       │                      │

Sin las 6 columnas, no entra. | La tabla es el contrato PND→PEI. ## 5. ACCIONES PRIORITARIAS + PLANTILLA LISTA PARA EL EJERCICIO

### 5.1 Cómo llenar la tabla (reglas para empleados)

| Columna | Regla de llenado | Error típico a evitar |
|---|---|---|
| **FOCO (INICIATIVA)** | Solo: `F1 Infraestructura dinamizadora…` o `F2 Ruta social…`. Si es ambos, declarar principal + justificar en Detalle. | Dejar en blanco o inventar un tercer foco. |
| **OBJETIVOS ESTRATÉGICOS** | Copiar el objetivo vigente ANI. **Información insuficiente para concluir** hasta levantarlo. No inventar objetivos. | Crear objetivos nuevos en la fila. |
| **PROYECTO** | Nombre único, verificable, con modo (F1) o frente (F2). | Nombre genérico ("mejorar infraestructura"). |
| **UNIDAD MEDIDA** | Una sola unidad: km, %, casos, proyectos, etc. | Mezclar unidades o dejar "varios". |
| **META 2030** | Número + unidad + fecha. Solo si hay línea base. Si no hay, escribir: `Por definir — línea base pendiente`. | Fijar meta sin línea base. |
| **DETALLE** | Cómo contribuye al Foco + criterios transversales (F1) o capacidades (F2) + supuestos/riesgos. | Texto promocional sin trazabilidad. |

### 5.3 Taller de priorización (20 minutos máximo)

| Campo | Contenido |
|---|---|
| **Nombre** | "Doble llave: F1 viable con F2" |
| **Objetivo** | Que cada equipo defienda 1 proyecto con scoring 1-5 y lo ubique en la Matriz Impacto-Esfuerzo. |
| **Duración** | 20 min |
| **Participantes** | Equipos directivos + técnicos (4-6 por mesa) |
| **Metodología** | Scoring silencioso → debate → consenso → pegado en matriz |
| **Instrucciones** | 1) Cada mesa llena 1 fila de la tabla. 2) Puntúa 9 criterios (1-5). 3) Ubica en matriz. 4) Declara su "doble llave" F1↔F2. |
| **Preguntas detonadoras** | ¿Qué pasa si este proyecto no tiene gestión social? ¿Cuál es su línea base? ¿Qué capacidad F2 necesita primero? |
| **Evidencia esperada** | 1 fila validada + scoring + ubicación en matriz |
| **Visualización** | Matriz Impacto vs. Esfuerzo en papelógrafo + tabla PEI impresa |

### 5.4 Checklist de validación (antes de aprobar una fila)

- [ ] ¿Tiene Foco único y justificado?
- [ ] ¿Tiene Objetivo Estratégico vigente (no inventado)?
- [ ] ¿Unidad de medida única y verificable?
- [ ] ¿Meta 2030 con línea base o marcada "por definir"?
- [ ] ¿Detalle declara criterios F1 o capacidades F2?
- [ ] ¿Scoring 1-5 completo y matriz ubicada?
- [ ] ¿Doble llave F1↔F2 declarada?
